# Monnie's Flower Quest

A polished mobile-first garden adventure built with React, TanStack Start, Tailwind CSS, and Phaser.

Guide Monnie through five handcrafted gardens, collect every flower, dodge the beetles, and unlock the garden gate.

## Features

- Five playable levels with different layouts, objectives, hazards, and music moods.
- Phaser canvas gameplay with React-powered title, HUD, pause, and result screens.
- Keyboard controls plus a virtual joystick for touch devices.
- Audio controls, game-state overlays, collection feedback, and gate-unlock effects.
- Social metadata and preview images for eventual hosting on your site.

## Local Development

```bash
npm install
npm run dev
```

The dev server runs on port `8080`.

## Production Build

```bash
npm run build
```

The project is Vite/TanStack Start based and is ready to connect to a static or Node-compatible host depending on how you want to publish it from your main site.
