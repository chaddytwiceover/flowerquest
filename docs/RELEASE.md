# Release

Release decisions belong to the Product Owner.

## Release Readiness

Before describing work as release-ready:

- Run the required validation commands.
- Run relevant gameplay and browser checks.
- Verify important UI on mobile dimensions.
- Capture screenshots for UI or visual changes.
- Report known limitations.
- Confirm Product Owner approval.

## PWA and Distribution

PWA and distribution work belongs in a dedicated phase. Improve installation, offline handling, asset caching, app icons, startup behavior, and standalone display only when that phase is approved.

Do not mix PWA/distribution work with gameplay mechanics, level redesign, Phaser migration, or broad UI changes.
