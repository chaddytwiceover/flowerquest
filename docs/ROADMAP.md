# Roadmap

Agents should generally follow this order unless explicitly redirected.

## Phase 0: Agent Foundation

Create concise repository guidance, establish supporting documentation, and define architecture boundaries.

## Phase 1: Regression Safety

Build automated gameplay coverage for all ten existing levels. Establish baseline behavior before architectural changes.

## Phase 2: Repository Cleanup

Audit unused app-builder systems and dependencies. Remove only clearly unused infrastructure.

## Phase 3: Phaser 4 Evaluation/Migration

Perform migration as an isolated technical project. Do not add gameplay during migration.

## Phase 4: Asset Loading and Performance

Move toward shared asset bootstrap plus per-level loading. Optimize major images and loading paths.

## Phase 5: Mobile UX Foundation

Improve safe areas, touch targets, movement feedback, responsive HUD, and control settings.

## Phase 6: Save and Progression

Add local save schema. Track unlocked levels, completions, stars, secrets, best times, and settings.

## Phase 7: Generic Interaction Framework

Create reusable interactions. Start with a small mechanic such as a switch or pressure plate.

## Phase 8: Objective System 2.0

Support objectives beyond collecting.

## Phase 9: Secrets and Stars

Introduce Secret Petals and level ratings.

## Phase 10: Permanent Adventure Tools

Introduce the first approved permanent ability.

## Phase 11: Levels 1-5 Redesign

Improve identity, pacing, exploration, and teaching. Do one level at a time.

## Phase 12: Levels 6-9 Redesign

Increase mechanic combinations and complexity.

## Phase 13: NPC / Story Framework

Add lightweight dialogue and environmental narrative.

## Phase 14: Level 10 Finale

Build a unique multi-stage conclusion.

## Phase 15: Game Feel Pass

Improve animation, particles, audio, camera, feedback, transitions, environment movement, and enemy readability.

## Phase 16: PWA / Distribution

Improve installation, offline handling, asset caching, app icons, startup behavior, and standalone display.

## Phase 17: Release QA

Full regression, full campaign playthrough, multiple phones, performance review, accessibility review, and release candidate.
