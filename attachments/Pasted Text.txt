BUG-FIX PRIORITY
==================================================

Classify discovered problems:

P0 — BLOCKER
Game cannot start, crashes, progression impossible, required collectible unreachable.

P1 — CRITICAL
Major gameplay mechanic broken, incorrect progression, collision exploit prevents intended play.

P2 — MAJOR
Noticeable gameplay/UI problem but demo remains completable.

P3 — MINOR
Visual/polish issue with little gameplay impact.

Fix:

ALL P0
ALL P1
ALL reasonable P2

Only fix P3 issues if the fix is extremely low-risk.

Do not destabilize the demo to chase cosmetic perfection.
